# WC Product Descriptions Editor

افزونه وردپرس برای ویرایش سریع **توضیحات کوتاه** و **توضیحات اصلی** محصولات ووکامرس در یک جدول واحد.

## امکانات

- لیست همه محصولات با فیلتر (نام، SKU، دسته، برچسب، نوع، موجودی و …)
- ویرایش درجا توضیحات کوتاه و توضیحات اصلی
- ذخیره با REST API (بدون رفتن به صفحه ویرایش هر محصول)
- دانلود قالب اکسل و آپلود برای به‌روزرسانی گروهی
- تبدیل متن توضیحات کوتاه به جدول HTML با AI (API متیس)
- استایل جدول در صفحه محصول

## پیش‌نیاز

- WordPress 6.0+
- PHP 7.4+
- WooCommerce (فعال)

## نصب

1. پوشه `wc-product-descriptions-editor` را در `wp-content/plugins/` کپی کنید.
2. از **افزونه‌ها → افزودن** پلاگین را فعال کنید.
3. بروید **ووکامرس → توضیحات محصولات**.

## استفاده

### ویرایش در پنل

- محصولات را فیلتر کنید، متن را در textarea ویرایش کنید و **ذخیره** بزنید.
- میانبر: `Ctrl + Enter` برای ذخیره سریع.

### اکسل

1. **دانلود قالب** — ستون نام محصول پر می‌شود.
2. ستون‌های توضیحات کوتاه و اصلی را پر کنید.
3. **آپلود** — فقط محصولاتی که نامشان در ووکامرس وجود دارد به‌روز می‌شوند.

### تولید جدول با AI

1. متن خام (مثلاً سایزبندی) را در **توضیحات کوتاه** بنویسید.
2. کلید API متیس را در بخش تنظیمات AI وارد کنید.
3. روی **تولید جدول AI** کلیک کنید.

> فقط متن داخل textarea به AI فرستاده می‌شود — نام، قیمت و موجودی محصول ارسال نمی‌شود.

## تنظیمات AI (متیس)

| فیلد | پیش‌فرض |
|------|---------|
| آدرس API | `https://api.metisai.ir/openai/v1` |
| مدل | `gpt-4o-mini` |
